# Thông tin file thật và đọc nền — 04/10/2026

Người dùng cho phép sửa R1/R2 sau [audit toàn luồng](FINAL_FLOW_REVIEW.md): popup Thông tin từng hiển thị codec/resolution/FPS/bitrate cố định theo extension, và đọc sidecar/ffprobe đồng bộ trước khi mở popup. Phase này sửa riêng hai lỗi đó; không đổi engine, DSP, thuật toán playlist/search, AI/ASR/dịch hoặc dữ liệu đã lưu. Không commit, build, update, tải model hay nâng dependency.

## Thay đổi

- `VideoInfoPopup.update_info` hiển thị trạng thái đang đọc rồi giao việc cho `ui.media_info_probe`. Stat nguồn/sidecar, đọc JSON và ffprobe đều chạy trên owned QThread; chỉ cập nhật Widgets trên GUI thread. Một lượt ffprobe lấy cả streams và format/tags, không gọi riêng lần nữa cho description.
- Dùng **đường dẫn media gốc từ item**, không lấy đường dẫn EQ cache đang được decoder phát. Codec, resolution, sample rate, channels và bitrate đọc từ stream thật. FPS phân biệt trung bình và danh định khi phải fallback; aspect có xét sample aspect ratio. Cover art `attached_pic` không bị coi là video. File nhiều stream dùng stream có disposition default, hoặc stream đầu tiên; đây là thông tin file, không màn hình thông số track đang chọn trong decoder.
- Bitrate là bitrate **audio stream**, không lấy bitrate toàn container để giả làm chất lượng audio. Không có số đo thì “Chưa rõ”; không có stream thì “Không có”/“N/A”. Không suy đoán MP3/FLAC/H.264/60fps theo extension. Duration ưu tiên container, thiếu thì giữ duration metadata có sẵn; source size/mtime được đọc lại từ file thật.
- Description vẫn ưu tiên item → ba sidecar theo thứ tự cũ → format tags. Giữ Unicode/plain text/newline và bỏ qua sidecar JSON lỗi. Hỗ trợ item object/dict, không ghi ngược vào `MediaMetadata`, sidecar hoặc library. `get_description_for_item` còn API đồng bộ cho compatibility; đường UI không gọi API này nữa.
- Cache **RAM LRU 32 entry**, key gồm source path/size/mtime_ns, signature ba sidecar, item description và duration fallback. Mở lại còn cùng context không spawn ffprobe; sửa nguồn/sidecar/context làm cache miss. Không cache kết quả lỗi để có thể retry; kiểm tra signature lại sau đọc và bỏ thông số nếu nguồn thay đổi giữa chừng. Không tạo cache/settings/schema mới trên ổ đĩa.
- Một worker hiện hành và một request mới nhất đang chờ; đổi bài hủy request cũ bằng interruption flag, gộp các request trung gian, bỏ kết quả stale bằng generation. Không đợi thread/process trên GUI trong tương tác thường. Process nền ẩn console, priority below-normal, ffprobe deadline 3 giây và poll cancellation 100 ms; worker thu hồi chính process của mình. Deadline này giới hạn ffprobe, không là cam kết thời gian cho mọi I/O filesystem.
- Đóng popup qua QDialog finished hủy request; owner cấp QApplication giữ worker đến finished. Popup đang mở cập nhật khi playback metadata đổi; MainWindow shutdown dừng/wait owner này trước quit. Giữ modal exec, frame/flags/tab/control/geometry và subtitle presentation guard hiện có, không tạo player/audio/video owner mới.

## Phạm vi source và compatibility

Ba production module cũ đổi: `video_info_popup.py` và hai adapter hẹp trong `PlaybackBar.set_media_info`/`MainWindow.closeEvent`; thêm một helper `media_info_probe.py`. Các source playback, audio policy/controller/cache, pipeline, save/load, downloader và hook Qt giữ nguyên.

Snapshot chính xác của phase này nằm ở [manifest](media-info/reviewed-sources.json), [diff](media-info/reviewed.patch) và [helper hash](media-info/helper-hash.json). `media_info_contracts` kiểm tra đầy đủ reviewed bytes (chỉ chấp nhận khác newline do Git) rồi phục hồi raw bytes trước phase để các gate cũ chạy. `audio_easy_contracts` gọi adapter mới trước chain cũ. Gate media-surface vốn đọc file trực tiếp cũng nối qua adapter; hash/AST/manifest lịch sử **không recapture hoặc bỏ kiểm tra**. Kiểm thử mới kiểm tra cả function whitelist và AST toàn phần còn lại.

`tools/check_media_info_checkout.py` dùng disposable `GIT_INDEX_FILE` rồi Git checkout-index với attributes thật; không stage/reset/commit vào index của người dùng. Bảo toàn byte helper và archive trong `.gitattributes`. Các thay đổi build/spec/requirements/xóa log và `docs/empty-subtitles/media/` đã có của người dùng được giữ nguyên.

- Regression mới: **14 tests** về metadata, default stream/cover art, rational/frame/pixel aspect, item/sidecar/tag precedence, cache hit/source/sidecar/duration/LRU invalidation, malformed/missing/timeout/source mutation, GUI thread/heartbeat, latest/coalescing/close/modal/empty, shell switch/shutdown và source gates. Có ffprobe thật trên MP4 AAC128k, WAV PCM, FLAC trong thư mục tạm; process timeout/cancel dùng child thật và code reap production. [Focused log](media-info/focused-tests.txt).
- Full discovery Python 3.11/Qt offscreen: **309 total = 298 pass +11 historical skip**, 100,004 s, [log](media-info/test-results.txt). Focused cuối **23 pass** (14 mới +9 media surface), [log](media-info/focused-tests.txt). Chỉ 11 historical skips cho architecture đã rollback; không skip thêm lỗi metadata. Lượt đầu có một gate media-surface bypass chain, được ghi lại ở [log đầu](media-info/test-results-first.txt), sau đó bổ sung adapter exact/hash để giữ baseline cũ.
- DPI 200%: **56 pass**, 16,633 s, popup mới + media surface + UI stability + spacing/caption + subtitle presentation; [log](media-info/dpi2-tests.txt). Không dùng offscreen để kết luận native screen FPS.
- **21 source/hash/AST gates**, 3,562 s, trên checkout Git tạm gồm 19 gate cũ và hai gate metadata/media-surface, [log](media-info/checkout-gates.txt). Index thật không đổi; whitespace cả file mới được kiểm tra qua index tạm, log diagnostic giữ nguyên whitespace qua attributes riêng.
- **8/8 video thật** trong `video/` đọc đúng codec/resolution/sample rate theo ffprobe độc lập; mỗi lần đầu một probe, tám lần mở lại **0 probe mới**; source SHA-256 giữ nguyên. Với `A Small Miracle(short).mp4`: AV1, 1080×1080, 25 FPS, 1:1, AAC128kbps, 44.100Hz, stereo. [JSON](media-info/real-media-probe.json), [log](media-info/real-media-probe.txt).
- Fault workload riêng: reader chậm giả lập 250 ms, `update_info` submission **0,259 ms**, async completion **257,293 ms**, GUI timer 10 ms chạy **25 ticks**. Audit trước sửa dùng reader cùng độ trễ ghi nhận submission 251,300 ms và 0 tick; đây là fault injection trên máy này, không phép đo native playback/FPS hay cam kết không lag trên mọi máy.
- **31/31 file dữ liệu/sub đã lưu giữ hash**: [before](media-info/saved-before.json), [after](media-info/saved-file-check.json). Không migrate/dịch lại/realign hoặc sửa file video/sub cũ.
- `git diff --check` đạt; source gates kiểm tra phần code không được phép đổi. Khởi động Qt hook và batch thumbnail cache vẫn ngoài phase này như scope đã thống nhất.

Suite dùng Qt/modal/worker/process và FFmpeg thật với fixture/media chỉ đọc; không chạy fresh Whisper/NLLB GPU, provider network hoặc bản EXE. Native Windows dialog/driver/nhiều thiết bị/EXE vẫn nghiệm thu riêng; các phép thử này không chứng nhận toàn app không còn lỗi trong mọi môi trường.
